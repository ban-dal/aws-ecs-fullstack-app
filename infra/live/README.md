# 서비스 기반 모듈

`infra/plan`의 환경별 원격 state 루트가 이 모듈을 호출한다. VPC, 두 AZ의 공개·비공개 서브넷, NAT 없는 라우팅, ALB·ECS 호스트용 보안 그룹, 비공개 ECR 저장소만 선언한다. EC2 인스턴스, ALB, 퍼블릭 IPv4와 공개 수신 규칙은 생성하지 않는다.

`preprod`는 `10.60.0.0/16`, `prod`는 `10.61.0.0/16`을 사용한다. 각 환경은 `aws-fullstack-lab-<environment>` 접두사로 이름을 분리한다. 공개 서브넷도 자동 퍼블릭 IP 할당을 끈다. 이후 EC2를 연결할 때 퍼블릭 IP와 비용을 별도로 결정한다.

적용·비용·종료 절차는 [운영 가이드](../../docs/operations.md#4-서비스-기반-적용)를 따른다.
