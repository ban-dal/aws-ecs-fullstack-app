# Task NNN: 제목

| 항목 | 값 |
| --- | --- |
| PR | 생성 후 링크 입력 |
| 작업 브랜치 | 브랜치 이름 |
| 상태 | 준비 / 진행 중 / 완료 |
| 시작일 | YYYY-MM-DD |
| 완료일·merge commit | PR merge 후 입력 |

## 목표와 완료 기준

- 해결할 문제와 사용자가 얻을 결과를 적는다.
- PR에서 확인할 수 있는 완료 기준을 적는다.

## 작업 내용과 결정

- 실제 변경한 코드·인프라·문서를 경로와 함께 적는다.
- 중요한 선택과 대안을 간결하게 기록한다.

## 재구성 절차

1. 필요한 계정·권한·도구 버전·입력값을 적는다. 비밀 값은 쓰지 않는다.
2. 실행 순서와 명령을 적거나 `docs/operations.md`의 해당 절을 연결한다.
3. 적용 후 확인 방법과 실패 시 복구 방법을 적는다.

## 검증과 운영 영향

- 실행한 검사와 결과, 실행하지 못한 검사의 이유를 적는다.
- AWS 예상 비용·무료 플랜 영향·리소스 종료 방법을 적는다.
- 실제 클라우드 적용 여부와 결과를 구분해서 적는다.

## 남은 사항과 다음 Task

- 이 PR 범위 밖의 일과 다음 Task 후보의 목표·완료 기준을 적는다.
