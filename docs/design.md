# 디자인 기준

## 현재 화면

첫 화면은 이 프로젝트가 어떤 실험인지 한눈에 보여 주는 소개 카드다. 주요 제목, 짧은 설명, 사용 중인 AWS 영역, 실행 환경을 순서대로 읽을 수 있다. 모바일에서도 한 열로 재배치된다.

## 경험 원칙

- 한국어를 기본 언어로 사용한다. 클라우드 서비스 고유명사는 공식 표기를 따른다.
- 상태와 환경은 텍스트로도 표시한다. 색만으로 의미를 전달하지 않는다.
- Next.js의 서버 렌더링을 기본으로 하고 꼭 필요한 상호작용이 생길 때만 클라이언트 컴포넌트를 쓴다.
- 단일 카드의 글자 대비와 작은 화면 여백을 유지한다. 터치 대상이 생기면 충분한 크기와 키보드 포커스를 제공한다.

## 디자인 토큰 초안

| 역할 | 값 | 사용처 |
| --- | --- | --- |
| 배경 | `#0b1220` | 전체 화면 |
| 카드 | `#111e32` | 내용 영역 |
| 본문 | `#c6d3e4` | 설명 문장 |
| 강조 | `#63d2ff` | 구분 레이블 |

현재는 CSS에 직접 정의했다. 화면이 늘어나면 `packages/ui`와 토큰 패키지로 옮길지 검토한다.

## 향후 디자인 작업

제품 기능을 추가할 때 사용자 시나리오, 화면 흐름, 빈 상태·오류 상태, 모바일 배치, 접근성, 구현 후 실제 브라우저 검증을 함께 기록한다. AI가 만든 시안은 구현 가능성과 사용자 목적을 기준으로 검토한다.
